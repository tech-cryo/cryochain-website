Connect the CryoChain app, Claude and live data

CryoChain app plugin. Point the map at your app’s feed, or push data from the app when the map runs inside it:

<script>
window.CRYOCHAIN_CONFIG = {
  appFeed: { url: "https://api.cryochain.co/map-feed",
             headers: { Authorization: "Bearer TOKEN" },
             refreshSeconds: 300 },
  parentOrigin: "https://app.cryochain.co"
};
</script>

// Or from code, at any time:
CryoChainApp.load({ lots, regions, hubs, need });
CryoChainApp.on("select", e => openDetails(e));

Regions take country, name, lat, lon plus optional notes, farmers, cold_hubs. Lots take product, country, region, grade, tons, harvest, pesticides, lab_tested, certifications, price_usd_kg. Inside a React Native WebView or iframe, send { type: "cryochain:data", payload } with postMessage; the map answers with select, filters, export and theme events. The full schema is in CryoChainApp.schema.

Claude. 1. Add a route on your server that adds your Anthropic API key and forwards the request body to the Claude Messages API. Then set it before this page loads:

<script>
window.CRYOCHAIN_CONFIG = {
  llmEndpoint: "/api/claude",
  model: "claude-sonnet-5-5"
};
</script>

2. To let Claude query the map as tools, pass CryoChainMarket.tools in your request and answer each tool call with CryoChainMarket.run(name, input). Tools: search_supply, country_profile, find_opportunities and set_view.

3. Exports load SheetJS and jsPDF from cdnjs when first used. To host them yourself, set CRYOCHAIN_CONFIG.libs = { xlsx: "...", jspdf: "..." }.

About the pesticide list. US status reflects EPA tolerances under 40 CFR Part 180. EU status reflects approval in the EU Pesticides Database. Chlorpyrifos is marked limited because EPA has proposed to keep US tolerances on 11 crops only, citrus among them, and the EU does not accept it. Rules change, so check the EU Pesticides Database and US tolerances for your crop before each shipment.

About the area filter. ECOWAS has 12 member states. Burkina Faso, Mali and Niger left in 2025 and now form the Alliance of Sahel States; they are included by default and marked as outside ECOWAS. Choose ECOWAS only to leave them out, or All West Africa to add Mauritania, which left in 2000.

About the country briefs. Briefs for Burkina Faso, Mali and Niger, and the market access alerts, use published sources gathered in November 2026 and are linked in each brief. The lots, tons and need estimates elsewhere remain sample data.
